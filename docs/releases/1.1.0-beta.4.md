# ArchiveDesk 1.1.0-beta.4 — build 19

macOS 14+ · Universal arm64/x86_64 · prerelease. Download the Universal DMG or application ZIP; matching source ZIP and SHA-256 checksums are included. Previous releases are retained.

- Bounded Auto detection for unflagged legacy ZIP names, with the detected choice
  visible in the browser. Listing, single-item preview and extraction share routing.
- Separate Auto/manual text-preview encoding, including GBK/GB18030, CP932,
  Big5, CP949, CP437/850, Windows-1252, CP866 and Windows-1251; Unicode/BOM handling
  remains available. Failed decoding can be retried without extracting again.
- Additional explicit ZIP code pages, strict round-trip conversion, binary/control
  rejection, bounded prefixes and stale-task/close cleanup.
- Password/CRC/path checks remain required before preview. Encodings never
  alter the original archive or transcode extracted file contents.

Local validation: 90 tests, 80 passed / 10 explicitly skipped / 0 failures. The original legacy Chinese ZIP's nine names, text preview and extracted bytes were verified; native UI wrong-encoding/manual-recovery checks passed. Hosted CI independently builds and tests before publication; private fixtures are not uploaded.

See docs/ENCODING.md for limits. The separate iOS 0.3.3 Beta 2 (build 10) also fixes legacy filename/text decoding and has its own simulator evidence; Mac and iOS do not share the same preview decoder implementation.
Auto is heuristic; mixed encodings, ZIP64/split archives, oversized metadata or
ambiguous short text may need manual selection. Unicode-extra archives retain
7-Zip's metadata handling. Filename-conversion mode remains read-only.

Universal arm64/x86_64, macOS 14+. Ad-hoc signing only; no Developer ID signing
or Apple notarization. Intel and older macOS hardware are not runtime-tested.
