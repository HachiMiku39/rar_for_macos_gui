# ArchiveDesk 1.1.0 Beta 5（build 21）

默认直接解压到所选目录。随机命名子文件夹与解压暂存都默认关闭，仅在设置中开启；解压不额外运行一次整包测试，创建压缩包时仍可选择完成后校验。

同名普通文件可选择“覆盖此文件”“全部覆盖”“不覆盖”或取消，全部覆盖只在当前压缩包内生效。覆盖前在目标磁盘将原文件改名为旁置备份，避免复制大文件。直接模式失败或取消可能留下不完整文件；备份不会自动删除。

开启暂存后，在目标磁盘的私有目录解码，再发布到目标；修复旧版占用启动盘暂存而误报空间不足的问题。旧编码 ZIP 的直接解压正确处理已有文件，保留旧编码文件名／正文菜单和密码预览。

本地真实大 RAR：原包约 141 GB，54,408 项，展开 258,615,668,301 字节；引擎成功，50,504 个文件逐项尺寸匹配，原包未修改。测试样本及私人内容不随发布提供。完整验证与限制见 VALIDATION.md。

macOS 14+，Universal arm64/x86_64。本版仍为 ad-hoc 签名，未使用 Developer ID 签名或 Apple 公证；没有新增 Intel／旧系统实机验证。路径、链接和解码器错误检查继续保留。压缩 TAR/UUE 的目录浏览预处理、媒体预览仍可能使用内部临时文件，关闭解压暂存不等于所有操作完全不使用临时文件。
