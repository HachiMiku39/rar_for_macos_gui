# ArchiveDesk 1.1.0-beta.3

macOS 14+ · Apple Silicon / Intel Universal · build 18 · 测试版

## 本版更新

- 新增压缩包内图片、音频、视频与文本预览；双击文件、按空格或右键“预览”。音乐显示系统可识别的标签和内嵌 JPEG / PNG 封面；音视频提供播放、暂停、时间轴和音量控制。
- 修复加密 ZIP 等归档内的文件预览：即使可以看到文件名，也需输入正确密码才能预览内容；支持错误密码重试及取消。密码只保留在当前归档会话内存，不写入参数、日志或设置。
- “最近打开”改为仅内存记录，退出 App（⌘Q）后清除，下次启动不恢复；清理旧版保存的路径与本 App 的系统最近文稿。不删除原始文件，不修改其他偏好。红色关闭按钮仅关闭窗口，并非退出 App。
- 新增可选 Miku 葱绿／粉色配色，与系统／浅色／深色外观独立，主窗口、预览和任务进度统一响应；保留标准主题与中英日文。
- 保留 1.0 的压缩／解压、批量队列、密码解压、选中项解压、校验、分卷、CPU / RAM / 读写速率与进度功能。

## 下载与安装

下载 `ArchiveDesk-1.1.0-beta.3-universal.dmg`，退出旧 App 后拖到 Applications 替换。
同时提供应用 ZIP、源码 ZIP 与 `ArchiveDesk-1.1.0-beta.3-SHA256SUMS.txt`；旧版本不覆盖。

**仅 ad-hoc 签名，未经 Developer ID 签名和 Apple 公证，不代表 Apple 审核。** 若系统阻止打开，可通过 Xcode 从源码构建，无需关闭系统安全保护。

## 验证与边界

本机 82 项测试：73 通过、9 因可选工具／样本缺失跳过、0 失败。已验证真实加密 ZIP 的取消／错误密码重试／正确密码文本预览，以及打开文件后退出重启不恢复历史。Universal Release 和签名完整性校验通过；GitHub Actions 另外执行干净构建、测试及包校验。

- Mac 预览使用 AVFoundation / AVKit / ImageIO，不是 iOS FFmpeg 后端；AV1 / MKV / WebM 等支持取决于系统和编码，不保证全格式播放。文本只读且有大小上限；不执行 HTML、脚本或包内程序。
- 预览需先提取所选文件至受限临时目录，不是零临时文件的直接流式播放。关闭预览会停止播放并清理该副本；临时清理不是安全擦除。
- 外置盘断开后读取可能仍显示通用 CLI 退出码 2；重新连接后可通过系统选择器重新选择文件。本版未完成全部外置存储权限生命周期测试。
- 未验证实体 Intel、旧 macOS 和 100 GB 全场景；不宣称经过独立安全审计。
- 创建 RAR 仍需用户另从 RARLAB 获取工具并遵守许可，App 不捆绑 RAR 创建器。内置 7-Zip 的许可及对应源码保留。

详见 README、VALIDATION.md 与 docs/MEDIA-PREVIEW.md。
