# ArchiveDesk 1.0 正式版

原生 macOS 压缩包管理器。支持 macOS 14+；Apple Silicon / Intel 通用安装包。

## 本版内容

- 新 Dock 图标：保留角色与压缩包主题，调整圆角、透明边距与阴影。
- 压缩、解压与测试自动显示进度窗口，包含阶段百分比、CPU、RAM、磁盘读写速度、目标卷容量、用时和取消。支持隐藏与重新打开。
- CPU 同时展示整机容量占比（0–100%）和活动监视器口径的进程占用（多核可超过 100%）。统计范围为 ArchiveDesk 与当前引擎。
- 批量解压队列、冲突策略应用到全部、SHA-256 / MD5 校验面板。
- Quick Look、单个文件拖出、旧 ZIP 文件名编码选择。
- RAR5 / ZIP / 7z / TAR / tar.gz / tar.xz 创建；RAR5 / ZIP / 7z 自定义分卷，最大 4 GiB。
- 保留 IPA / APK 信息检查、中文/英文/日文界面与语言包导入功能。

## 下载与安装

下载 `ArchiveDesk-1.0.0-universal.dmg`，退出旧版本后，将应用拖到 Applications 替换。
同时提供应用 ZIP、源码 ZIP 和 `SHA256SUMS.txt`。旧 Beta 发布保留，不覆盖旧附件。

**重要：尚未经过 Developer ID 签名和 Apple 公证。正式版状态不代表 Apple 已审核。** 不建议关闭系统安全保护；可使用 Xcode 从源码构建。

RARLAB 的 rar 不随应用分发；创建 RAR 需用户自行安装并遵守其许可。内置 7-Zip 的许可和对应源码随项目提供。IPA/APK 检查不提供 DRM 绕过或脱壳功能。MD5 仅用于兼容旧校验值。

## 已知限制

- Quick Look / 拖出单个普通文件需临时提取，上限 512 MiB；不支持文件夹拖出和嵌套归档预览。
- ZIP 分卷使用 `.zip.001`，不是传统 `.z01`；FAT32 建议每卷不超过 4095 MiB。
- 图标为静态 ICNS，不是 Icon Composer 动态分层图标。
- 未进行实体 Intel Mac 测试或完整 100 GB 归档压力测试。更多限制见 README 和 VALIDATION.md。
