# ArchiveDesk 1.1.0-beta.1

macOS 14+ · Universal 2 (Apple Silicon + Intel) · build 16.

## 新增

- 压缩包内视频／音频的独立预览窗口：播放、暂停、跳转、音量，视频原生全屏，音频 ±15 秒。
- 音乐标签与内嵌 JPEG／PNG 封面；图片缩略与方向处理；UTF-8 / UTF-16 只读文本预览和复制。
- 双击、空格、右键／工具 → 预览；原有 Quick Look、默认应用打开及拖出文件保留。
- 提取校验完成后才预览，不自动播放；关闭／切换／失败清理副本、播放器和观察器。
- 中英日文界面和英语源语言包模板更新。

## 兼容与安全说明

采用 macOS 系统 AVFoundation / AVKit / ImageIO，不捆绑 iOS 的 FFmpeg。
MKV/WebM/AV1 等格式不保证与 iOS 相同的播放能力；不支持时可解压后使用其他播放器。
媒体最多 512 MiB；图片最多 32 MiB / 3200 万像素，文本最多显示前 256 KiB。
外部媒体引用被禁止，HTML/SVG 只按纯文本显示；播放能力不等同于解压能力。

这是本地开发候选版，尚未创建 GitHub Release，未经过 Developer ID 签名／公证。
请参阅 [媒体预览说明](../MEDIA-PREVIEW.md) 了解系统解码器内存限制及测试边界。
