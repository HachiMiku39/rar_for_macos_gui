# ArchiveDesk 1.1.0-beta.2

macOS 14+ · Universal 2 · build 17. 本地开发版，尚未发布 GitHub。

- 新增可选 **Miku · 葱绿与粉色** 主题：青绿色强调色、少量粉色点缀、轻染色玻璃面板。

- 主题和系统／浅色／深色外观独立，主窗口、预览、任务进度及设置统一响应。
- 保留系统语义文本、错误／警告颜色，并尊重“降低透明度”；不更换 Dock 图标。
- 中英日文和英语语言包模板同步更新。保留 beta.1 的全部预览功能。
