# ArchiveDesk 1.1.0 Beta 6（build 22）

本版修复了 macOS 在并发保存、取消任务和跨压缩包拖出文件时的问题。

- 确认覆盖期间，若另一个应用重新保存同名文件，解压会停止替换并保留新版本。归档编辑同样会核对原包身份。
- 直接解压会把“不覆盖”的条目传给解压引擎，并按引擎实际写入数显示结果。已跳过的文件随后被移走，也会保持跳过。
- 取消只作用于原任务。切换压缩包后，Finder 延迟取数时会拒绝已经过期的拖出请求。

下载 Universal DMG，退出旧版，再把 ArchiveDesk 拖入“应用程序”。发布附件包含应用 ZIP、源码 ZIP 和 SHA-256 校验文件。最低系统为 macOS 14。当前使用 ad-hoc 签名，尚未获得 Apple 公证。

Apple Silicon 上 106 项回归通过，5 项跳过，0 项失败。本轮没有 Intel 实机或外置 exFAT 盘复测。外部程序在解压时更换源包或移动目标父目录仍有竞态风险。[完整验证记录](https://github.com/HachiMiku39/rar_for_macos_gui/blob/v1.1.0-beta.6/VALIDATION.md)
