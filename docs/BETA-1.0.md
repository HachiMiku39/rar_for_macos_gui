# 1.0.0-beta.1 行为与边界

## beta.2：独立进度窗口

压缩、解压、批量队列、归档测试启动后自动显示非模态任务窗口。进度与主窗口共享数据，不再受主窗口底部空间或队列弹层遮挡影响。标题显示任务、正文显示当前阶段／百分比与用时；CPU/RAM/进程读写速率每 0.5 秒更新，另显示目标磁盘已用和剩余容量。没有引擎百分比时显示活动条，短于一个采样周期的任务可能没有 CPU 或速率数据，不伪造读数。

关闭／隐藏仅收起窗口；从工具菜单或主窗口底部“任务进度”可恢复。取消后显示“正在取消”，实际退出才变成已取消。覆盖冲突出现时让出前台，处理后恢复进度窗口。任务结束后保留完成／失败／取消状态、用时和最后一次资源采样，开始下个任务时重置；不是持久化任务历史。

## 队列与冲突

拖入多个归档会创建队列，也可从工具菜单选择。队列顺序执行，不争抢内存和 I/O；普通文件拖入仍进入创建界面。开始后不再接收追加任务，关闭队列窗口不会停止工作，可从工具菜单再次打开；取消整队停止当前任务并将余下项目标记取消。失败的任务保留错误状态，后续继续。队列不跨应用重启保存，不提供并行、暂停、断点续传或自动重试。

每个压缩包使用同名目录；同名归档、已有目录会按所选冲突策略合并，不默默覆盖。多段 tar 后缀会整体去除，分卷只添加首卷。坏包可能留下空的同名文件夹。一个批次使用同一密码和 ZIP 编码；不同密码／编码的包请分批处理。

覆盖提示的“应用到本压缩包的全部冲突”仅在当前归档内有效，下一个任务重新询问；可跳过、替换并备份、自动重命名。取消单个冲突任务不等于取消整个队列。合并阶段取消可能保留已经完成的文件，不做破坏性的全局回滚。

## 校验工具

SHA-256 / MD5 使用固定 1 MiB 读取缓冲。拒绝最终符号链接、设备、管道及目录，检测读取期间的大小与时间戳变化。支持多文件计算、每行复制纯校验值，以及复制带路径的结果报告。结果报告并非可直接导入的 GNU 清单。

导入格式为 `hash  relative/path` 或 `hash *relative/path`，支持 SHA-256（64 位十六进制）与 MD5（32 位）、UTF-8、CRLF、以 # 开头的注释。清单最大 1 MiB / 10000 项；选择根目录，拒绝绝对路径、..、反斜杠、重复及 Unicode/大小写冲突路径、链接父目录。逐文件显示一致／不一致／读取错误。不支持 GNU 反斜杠转义文件名、BSD 格式或数字签名认证。MD5 不是安全认证算法。

## Quick Look 与拖出

选中文件后使用工具／右键菜单“快速查看”。系统 Quick Look 支持哪些具体文档、图片、音视频编解码器取决于 macOS 及已安装扩展。

文件名列可拖出单个普通文件至 Finder，利用 NSItemProvider 按需产生文件副本。文件夹、多选整批拖出及大于 512 MiB 文件请使用“解压选中”。导出先校验路径和大小，解码成功、CRC 正常后才提供 URL。拖出不执行内容；预览另有可执行文件、脚本、伪装文件和嵌套归档拦截。临时副本退出时清理，异常退出可能留下副本；预览／默认应用中的修改不会写回归档。

## ZIP 编码

Auto 继续使用内置 7-Zip。官方 macOS 7zz 的 -mcp 对旧编码没有实际转换能力，故手动编码切换到独立的 ArchiveDeskZIP 进程，使用 macOS 系统 libarchive 的 zip:hdrcharset。程序没有自写 ZIP 解码器，GUI 中也不加载原生解压代码。读取列表、全部／选中解压及临时导出统一使用同一后端与编码；UTF-8 标志有效时优先保留 UTF-8。无法转换、CRC 错误、损坏和不支持的算法返回任务错误，不静默宣称成功。

适用常规 ZIP / ZIPX（以系统库实际支持的压缩算法为准），多卷旧编码 ZIP 不保证兼容，遇到不支持会失败。手动编码模式不编辑原归档。系统 libarchive 会把部分旧 DOS 反斜杠路径标准化为目录分隔符；转换后的路径仍需通过安全检查。系统库版本随 macOS 更新，不能将单机验证推及所有旧系统。

## TAR 与分卷

TAR 用系统 bsdtar 创建 PAX，tar.gz / tar.xz 再通过内置 7-Zip 压缩外层。暂存成功及可选测试之后才提交结果；没有壳脚本拼接参数。保留普通权限和修改时间，禁用 AppleDouble、ACL、xattr 自动附带。输入名不允许以 @ 开头（bsdtar 特殊操作数），不保存所有权等完整备份元数据。

tar.zst 延后：本次不额外引入 zstd 可执行文件，现有 7-Zip 能解压 zstd，不提供 zstd 创建。TAR 不提供密码或分卷；RAR5 / ZIP / 7z 提供 1–4096 MiB 分卷（可输入 GiB，需对应整数 MiB）。4 GiB = 4294967296 字节；FAT32 单文件上限略小，请选不超过 4095 MiB。ZIP 是 .zip.001 分割形式，需要支持该形式的工具。

## 安全与性能声明

继续使用独立进程失败隔离、进程内存预算、磁盘空间检查、私有暂存、CRC 后合并和原子文件提交。ZIP 适配器还启用 libarchive 安全路径与禁止覆盖选项、拒绝链接和特殊文件、固定 64 KiB 解码缓冲、检查实际大小。新增校验计算可取消，无大文件整块读入。

这些措施不是权限沙箱或完整 TOCTOU 防御。目录索引仍有内存上限，100 GB、真实磁盘耗尽、多种旧系统及 Intel 实机仍待验证。不开发 GPU 解压，也不宣称达到商业成熟产品的完整安全保证。
