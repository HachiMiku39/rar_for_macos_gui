# WinRAR 功能在 macOS 上的取舍

## 当前已实现（1.0 beta）

| 截图中的能力 | ArchiveDesk 实现 |
| --- | --- |
| 压缩格式 | RAR5、ZIP、7z、TAR、tar.gz、tar.xz；RAR 需用户另行安装 |
| 压缩方法 | 仅存储、最快、快速、标准、较好、最好 |
| 字典大小 | RAR 4–256 MB；限制上限避免不合理的内存需求 |
| 固实压缩 | RAR5、7z；ZIP 不支持 |
| 密码 | RAR5/7z 可加密文件名；ZIP 使用 AES-256，文件名仍可见 |
| 分卷 | 三种格式均可；保存到独立新文件夹，避免覆盖已有分卷 |
| 压缩后测试 | 默认启用；RAR 使用原生 -t，ZIP/7z 创建成功后再测试；测试失败不报告整体成功 |
| 配置文件 | 保存一份默认压缩配置；不保存密码、源路径、分卷大小和恢复比例 |
| BLAKE2 校验和 | RAR5 使用 BLAKE2sp |
| 快速打开信息 | RAR 自动／不添加／全部添加 |
| 不压缩直接存储 | RAR 使用官方默认的已压缩扩展名列表 |
| 文件排除 | 每行一条模式，支持 * 和 ?；拒绝绝对路径、.. 和 @ 列表 |
| 多线程 | 自动或建议上限 1–64；实际使用受引擎、格式及算法限制 |
| 时间 | RAR 保存修改时间、访问时间及精度；ZIP/7z 使用默认策略 |
| 压缩包信息 | 当前已加载列表中的文件数、显式目录数、未压缩字节数，不冒充完整格式属性扫描 |

新增批量解压队列、冲突应用到全部、SHA-256/MD5 面板、原生 Quick Look、单文件拖出与旧 ZIP 编码选择。0.7 起可编辑未加密、单卷 RAR/ZIP/7z，并保留原包备份。容量和格式限制见 README。

## 暂不移植

- **压缩后删除、擦除、回收站模式**：避免压缩或校验失败导致源数据损失。本版始终保留源文件。
- **锁定包、加密包或分卷编辑、文件夹重命名**：暂不支持。普通未加密单卷已有安全副本编辑流程。
- **Windows 自解压程序**：不能直接作为原生 macOS 安装包使用，也涉及签名、公证及载荷执行风险。
- **Windows 创建时间开关**：RAR Unix 的 ctime 是状态变更时间，不是 birth time；不提供容易误导的同名选项。保存访问时间也不承诺还原源文件 atime。
- **任意额外参数**：不暴露可绕过应用安全约束的自由参数输入框；参数由受验证控件生成。
- **邮件发送、备份调度、逐文件建包、修复向导、注释、重复文件引用、完整文件管理器、基准测试**：留待后续独立设计，不放置无效勾选项。本轮未启动基准测试或自动后台任务。

## 实现依据

参数依据官方 RAR 7.23 随附 rar.txt，以及 7-Zip 26.03 MANUAL。RAR -tsc 在 Unix 上的语义与 Windows 不同；ZIP 不支持文件名加密。应用通过 posix_spawn 参数数组运行独立引擎，不使用 shell 拼接命令。

不复制 WinRAR 商标、图标或窗口皮肤。功能沿用 macOS 原生控件、SF Symbols 与 Liquid Glass 设计。
